## 1. 目標3「共有するほど減る」を成立させる最小の機構

### ★結論：新しい索引を作らない。**語彙を1本に揃えるだけ**。

```
① 症状が起きる    → symptomVerdicts が ★症状ID を出す（既にある）
② 共有テキスト    → その症状IDを必ず載せる（★1行足すだけ）
③ 受け取った側    → hub.mjs find --sig "<症状ID>" で既知原因に当たる
④ 原因が分かったら → ai-hub にその症状IDを triggers として登録
⑤ ★次の人は ③ で当たる ＝ 往復が1回減る
```

★**⑤が「共有するほど減る」の実体**。索引が育つのは④のときだけ。

### ★なぜ「別物を作る」を却下したか

会議は「新しい共有ログJSONL＋resolvedAt で機械集計」を提案した。★却下する。

- ★`resolvedAt` を誰が書くのか＝**人が手で書く登録簿**になる。
  このキットの実損記録：**3ヶ月で登録1件のまま／10指標中2つしか動かない**。
- ai-hub は既に **40件が生きて動いている**（triggers 245件）。
  ★作り直しは「既存資産を薄く束ねる」原則に反する。

### ★ただし④は人がやる（＝死ぬ）ので、死なせない工夫が要る

★**「登録して」と頼むのではなく、登録していない症状IDの数を機械が数える。**

```
symptomVerdicts の症状ID  … 機械が読める（コードにある）
ai-hub の triggers        … 機械が読める（index.json にある）
⟹ ★差分＝「まだ索引に無い症状」が機械的に出る
```

これは今日入れた `improvement-staleness` とまったく同じ形。
★**強制しない。数を見せるだけ。**

## 2. 目標1「1発で解決」の測れる定義

### ★結論：「往復回数」を直接の指標にしない。

会議は「往復0回」を提案した。★**測り方に致命的な穴がある**：

- 誰が「解決した」と宣言するのか＝★申告。嘘をつける・そもそも報告されない。
- ★このキットの掟「強制すると嘘のデータが入る」に正面から当たる。

### ★代わりに測るもの：**索引ヒット率**

```
共有テキストに載った症状ID のうち、
ai-hub で ★該当ありだった割合
```

- ★機械だけで測れる（人の申告が要らない）。
- ★偽装しにくい（ヒットさせるには本当に索引を育てるしかない）。
- ★「1発で解決」の代理として素直：
  既知原因に当たれば、調べ直す往復が要らない。

★**この検査が判定しないこと**：ヒットした原因が**正しいか**は判定しない。
索引が間違っていれば間違った所へ誘導する。★正しさは人が確かめる。

## 3. 共有テキストに載せるもの／絶対に載せないもの

| 必ず載せる | 理由 |
|---|---|
| ★症状ID（正規化済み） | ★これが無いと索引が引けない＝共有の意味が消える |
| 判定した理由（1行） | 人が検算できる |
| 測れなかった項目 | ★「無い」と「まだ分からない」を分ける |
| 版・buildId | 再現の起点 |

| 絶対に載せない | 防ぎ方 |
|---|---|
| 絶対パス（`C:\Users\<名前>\...`） | ★機械で除去。人のレビュー前提にしない |
| トークン・鍵らしき文字列 | 同上 |
| ユーザー名・ホスト名 | 同上 |

### ★会議の `secretlint` 案は保留

★この環境に**未導入**（`require.resolve` で確認）＝新規依存になる。
キットの原則「薄く束ねる」に反するので、
★まず**自前の正規表現フィルタ**で始め、足りなければ後から入れる。

## 4. ★5年後も死んでいないために「数で固定」するもの

★オプトイン（人が登録する）を含むものは全部却下した。

| 固定するもの | 機械が数えられるか | 恒真にならない理由 |
|---|---|---|
| ★selftest を持たない検査の数 | ✅ コードを走査 | 検査を増やすと必ず動く（今日実装・毒で確認） |
| ★索引に無い症状IDの数 | ✅ コード×index.json | 症状を足すと必ず動く |
| ★測れなかった(exit 2)の数 | ✅ 実行結果 | ★0に混ぜられない構造にした（今日実装） |
| 検査の本数 | ✅ ファイル走査 | — |

### ★却下したもの（理由付き）

- **共有件数 / 解決件数** … ★人の申告。嘘が入る。
- **手動登録数** … ★オプトインそのもの。3ヶ月で死んだ実績がある。
- **アンケート・満足度** … ★機械が数えられない。
