# 13_INFLUENCER_FIRST — 「宣伝して」と頼まず、発信者をファンにしてから一緒に売る（集客の設計の決まり）

## 0. 一言でいうと

**発信者に「宣伝してください」と頼まない。まず商品を使ってもらい、本当に好きになった人とだけ、その人専用の形で長く一緒に売る。**
**100万人に1回見せるより、深く信頼されている人を通して10万人に10回届ける。**

公開されている例: 健康ドリンクの AG1 は、有名人に1回だけ宣伝させるのではなく、実際に毎日使っている数百人のポッドキャスターに、長い期間くり返し自分の言葉で話してもらう形で売上を大きく伸ばした（公開報道ベース。数字は各自で出典を確かめる）。

## 1. なぜ全体の決まりにするか（今の方針とのつながり）

| 今の方針 | インフルエンサーファーストでどう効くか |
|---|---|
| **北極星 LTV÷CPA**（[07](07_GROWTH_METRICS.md) §1） | 信頼されている人からの紹介は、広告より少ない費用で来てもらえる（**CPA↓**）。成果報酬なら、売れた分しか払わないので CPA の上限が先に決まる。くり返し聞いて「生活の習慣」として入った人は続きやすい（**継続率↑ → LTV↑**） |
| **ガードレール**（07 §3） | 「お金をもらって褒める」は信用を削る数字の作り方そのもの。**気に入った人にだけ頼む・広告の表示をしてもらう**ことで、ガードレールの内側で数字を上げる |
| **無料ユーザーの価値 V_free**（07 §2-1） | 発信者に無料で使ってもらう費用は「種まきの原価」。その人が気に入って紹介してくれたら、浮いた CPA と K（連れてきてくれる人数）として返ってくる。デジタルの商品は渡す原価がほぼゼロなので特に相性が良い |
| **100年メンテナンスのいらない設計**（[01](01_CORE_RULES.md) §2-1） | 単発の宣伝は毎回お金と手間がかかる。気に入った人との長い関係（契約・共同事業＝JV）は、一度作れば何度も働く。専用ページ・専用リンクは型（ひな型）で作り、毎回ゼロから作らない |
| **人の手を使わない**（[08](08_NO_HUMAN_HANDS.md)） | 候補探し・数字の表・連絡文の下書き・専用ページ・計測は AI がやる。人に残るのは「送る」と「契約」のOKだけ（§4） |
| **商品インパクト** | 商品を「何が優れているか」ではなく「お客さんの面倒くささをいくつまとめて消せるか」で言える形にする（§2 の1番）。これが言えない商品は、誰の口からも広まらない |

## 2. 決まり（集客・新サービスを設計するとき、この順で当てる）

1. **消す面倒くささを1行で書く。** 企画書・LP の冒頭に「この商品は、誰の・どんな面倒くささ（手間・迷い・決めること）を、いくつまとめて消すか」を1行。機能の多さ・性能の数字で競う書き方を先にしない。
2. **「誰の信頼を借りるか」を広告より先に考える。** 集客の計画には、①自分の発信（[DISTRIBUTION-ROUTINE](../DISTRIBUTION-ROUTINE.md)）②**信頼されている発信者・お客さんのつながりを持つ人**（この文書）③広告、の順で書く。広告は ROAS で選ぶ最後の手段。
3. **候補はフォロワー数で選ばない。信頼の深さで選ぶ。** 見る数字は §3 の「信頼密度」。長く聞かれる・見られる発信（音声・長い動画・ライブ・LINE配信・メルマガ）をしている人を優先する。すでに商品を使ってくれているお客さんの中の発信者が一番早い。
4. **1人に賭けない。** 大物1人に大きく払うより、濃いファンを持つ小さめの発信者10〜50人に小さく試し、数字を見て、売れる人に集中する。
5. **5つの段で進める（飛ばさない）。**
   1. **渡す**: 「宣伝して」ではなく「まず使ってみて」。投稿を条件にしない。
   2. **気に入った人だけ次へ**: 気に入らなかった人には紹介を頼まない（「お金をもらったから褒める」が一番弱く、ガードレール違反に近い）。
   3. **その人専用の形を作る**: 専用ページ・専用リンク・専用コード（特典）を用意し、**誰の紹介で何件売れたかを数えられるようにする**。
   4. **本人の言葉で話してもらう**: 台本を渡さない。「なぜ使っているか」を本人の言葉で。ただし法律で必要な表示・言ってはいけない表現は会社が先に伝えて守ってもらう（§6）。
   5. **売れる人とは長く組む**: 単発で終わらせない。定期的に紹介してもらう契約・一緒に専用の商品やパッケージを作る共同事業（JV）へ近づける。
6. **最初の連絡の原則**（文面の型はこのリポに置かない。毎回、相手に合わせて AI が下書きする）:
   - 連絡する前に、その人の発信を実際に見て・聞いて、具体的な回・話を挙げる。
   - お願いは「使ってみてほしい」だけ。「投稿して」「1投稿いくら」から始めない（広告枠を買うだけになり、お客さんにも案件だと伝わる）。
   - 商品の説明は1〜2行（§2 の1番の1行）。
   - 断りやすく書く（「合わなければそれで大丈夫」）。
   - 使ってもらって2〜3週間後に感想を聞く（良い所も、いまいちな所も）。いまいちな所は商品の改善に回す（07 の NPS・解約理由と同じ扱い）。
7. **数字で決める。** §3 の段ごとの人数表を作り、次の段へ進む条件を先に書く。感覚で「この人は良さそう」と決めない。

## 3. 見る数字（07 §2 に足す物差し）

**信頼密度** = その人とフォロワーの信頼の深さ × 何回くり返し紹介してもらえるか。フォロワー数・表示回数（リーチ）は主役にしない。

| 見る所 | 数字 | 向き |
|---|---|---|
| 候補を選ぶ | 毎回最後まで見る・聞く人数／コメント数／ライブに来る人数／フォロワーが付いている長さ／長い発信（音声・長尺動画・配信）をしているか／自社のお客さんとの相性 | ↑ |
| 進み具合 | 候補 → 連絡した → 使ってもらった → 気に入った → 専用の形で小さく紹介 → 売れた → 長期契約・JV、の**段ごとの人数と次へ進む率** | ↑ |
| 1人ずつ | 専用リンク・コード経由の新規数／その人経由の CPA（払った額 ÷ 来た人）／その人経由のお客さんの継続率 | CPA↓・継続↑ |
| 続いているか | 3か月・半年・1年と、定期的に紹介が続いているか／本人が気に入ったまま話しているか | ↑ |
| 全体 | **パートナー経由の割合**（新規のうち発信者の紹介で来た割合） | ↑ |

測れていない数字は「まだ測れていない」と書く（07 §5）。専用リンク・コードが無いまま始めると、誰が効いたか後で分からなくなる——**専用の形（5段の3）は計測の仕組みでもある**。

## 4. AI がやること／人に残すこと（08 と同じ線引き）

| AI がやる（人を待たない） | 人（りんく）に残す |
|---|---|
| 消す面倒くささの1行・集客計画の下書き | — |
| 候補探し（公開されている発信を調べ、§3 の数字で表にする） | — |
| 相手ごとの連絡文の**下書き**（§2 の6番の原則で） | **送ること**（プロジェクトの外への送信＝戻せない操作。CLAUDE.md「確認なしでやってよいこと」表の最下段。メールは下書きカードで見せてから） |
| 専用ページ・専用リンク・専用コードを作る（ひな型から）・計測を仕込む | — |
| 段ごとの人数表を更新し、次に集中する人を数字で決めて報告する | — |
| 報酬・期間・表示の条件の**案**を書く | **契約・お金の約束**（お金がかかる操作＝OK要。条件は書面で決める） |

★「人に頼む理由」は 08 の書き方に従う。送信・契約以外（候補の比較・どの人に集中するか）は、人に選ばせず §5 の順で自分で決めて報告する。

## 5. 判断の順番（07 §4 の「来てもらう」段の細目）

1. §6（法律・表示・本当の体験だけ）を割る案は捨てる。
2. 07 §4 の順（ガードレール → LTV÷CPA）で、より上がる方。
3. 同じくらいなら、**信頼密度が高く・長く組める方**（一発の大きなリーチより、くり返し届く方）。
4. まだ同じなら、**専用の形で数えられる方**（後から効いたかが分かる方）。

## 6. 守ること（ガードレール。07 §3 に足す）

- **広告であることを表示してもらう。** 会社が依頼・報酬・商品提供をして紹介してもらうときは「広告」「PR」などの表示が要る。日本では 2023年10月から、広告であることを隠した宣伝（ステルスマーケティング）が景品表示法の規制の対象（消費者庁の告示・運用基準で確かめる）。
- **本当の体験だけ。** 使っていない人に「使っている」と言ってもらわない。気に入った人にだけ頼む（5段の2）は、この決まりでもある。
- **言ってはいけない表現を先に伝える。** 健康食品・化粧品・お金（借金・投資）などは、効き目や結果について言えない表現がある（医薬品医療機器等法・健康増進法・景品表示法・貸金業法など）。会社の責任で先に伝え、紹介の内容を確かめる。数字や実績は出典つき（CLAUDE.md 基準③）。
- **条件は書面で。** 報酬・期間・表示の方法・使ってよい素材は契約書で決める。
- **プライバシー。** 専用リンク・コードで数えるのは「何件来たか・売れたか」まで。紹介で来た人を個人として発信者に渡さない（[01 §5-1](01_CORE_RULES.md)）。

## 7. 機械検査（どこまで機械で見られるか）

- **見ていない（理由）**: 「この発信者は信頼が深いか」「連絡文が押しつけになっていないか」は意味の判断で、作る前に機械で正しく測れない。
  連絡文に「1投稿いくら」「投稿してください」などが入っていないかを調べる検査は作れるが、まだ実損が無いので足さない（CLAUDE.md「新しいルールを書いたら機械検査化を検討する」節の3番＝実損が出てから足す）。
  実際に送った連絡で問題が出たら、そのときに下書きの検査（禁句の grep）を `check-human-handoff` と同じ場所に足す。
