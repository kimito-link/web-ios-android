# 03_REVIEW_CHECKLIST

## 実装品質

- [ ] 要件を満たしている
- [ ] 重複実装がない
- [ ] 変更理由が説明できる
- [ ] テストが追加または更新されている

## UI/レスポンシブ

- [ ] モバイルで崩れない
- [ ] タブレットで崩れない
- [ ] デスクトップで崩れない
- [ ] 主要操作（CTA/フォーム）が常に操作可能

## URL / SEO / 配信

- [ ] URL が `/price/` 形式になっている
- [ ] `index.html` が公開URLに出ていない
- [ ] `www` あり/なしが統一されている
- [ ] `http` → `https` の 301 リダイレクトが有効
- [ ] canonical が正規URLと一致している

## セキュリティ

- [ ] シークレットがコード・ログに含まれない
- [ ] 入力値検証を実装している
- [ ] XSS/SQLi/CSRF の主要対策が入っている
- [ ] （公開前4問・[01_CORE_RULES §5-1](01_CORE_RULES.md)）秘密がブラウザ/アプリに届くコードに埋め込まれていない
- [ ] （同）認証・認可がサーバー/DB側にあり、未ログイン・別ユーザーの直接API呼び出しを実際に拒否した
- [ ] （同）他人のデータを閲覧・変更・削除できないことを、他人のIDを指定して実際に確かめた
- [ ] （同）課金されるAPIに認証＋レート制限＋プロバイダ側の上限があり、大量リクエストで高額請求にならない
- [ ] （同・§5-1a）公開前に `/claude-security` を走らせ、**いまのコード（HEAD）**に対する結果で CRITICAL / HIGH が残っていない（`node templates/scripts/check-security-scan-ran.mjs` が exit 0）

## コードコメント

- [ ] 新規ファイルの先頭に、役割・使い方・なぜ要るかが書かれている（[01_CORE_RULES §5-2](01_CORE_RULES.md)）
- [ ] 触ったコードのコメントが、変更後の挙動と食い違っていない

## ストア審査（Apple・2026-10-16改訂）

- [ ] 審査メモに、その時点の**全機能**と「サーバー配信で機能が決まる作りか」が書かれている（[01_CORE_RULES §5-3](01_CORE_RULES.md)・2.5.19）
- [ ] 審査後にサーバー側だけで新しい種類の機能（決済・UGC・AI生成・外部リンク）を足していない。難読化・休眠機能が無い
- [ ] クリエイティブアセット（ヘッダー等）に、価格・割引・No.1等の主張・他アプリへの言及が無く、全年齢向け（2.3.14）。画像は目視した

## デプロイ可否

- [ ] CI が成功している
- [ ] 影響範囲を説明できる
- [ ] ロールバック手順が明確
