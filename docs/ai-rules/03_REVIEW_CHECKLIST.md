# 03_REVIEW_CHECKLIST

## 実装品質

- [ ] 要件を満たしている
- [ ] 重複実装がない
- [ ] 変更理由が説明できる
- [ ] テストが追加または更新されている

## UI/レスポンシブ

- [ ] モバイルで崩れない
- [ ] タブレットで崩れない
- [ ] デスクトップで崩れない
- [ ] 主要操作（CTA/フォーム）が常に操作可能

## URL / SEO / 配信

- [ ] URL が `/price/` 形式になっている
- [ ] `index.html` が公開URLに出ていない
- [ ] `www` あり/なしが統一されている
- [ ] `http` → `https` の 301 リダイレクトが有効
- [ ] canonical が正規URLと一致している

## セキュリティ

- [ ] シークレットがコード・ログに含まれない
- [ ] 入力値検証を実装している
- [ ] XSS/SQLi/CSRF の主要対策が入っている

## デプロイ可否

- [ ] CI が成功している
- [ ] 影響範囲を説明できる
- [ ] ロールバック手順が明確
