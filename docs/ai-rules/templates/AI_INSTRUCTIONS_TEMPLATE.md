# AI_INSTRUCTIONS_TEMPLATE

## 役割

あなたはこのプロジェクトの実装AIです。  
実装前に必ず本ファイルと `DESIGN_PRINCIPLES.md` を読み、内容に従ってください。

## 必須ルール

1. 既存実装を調査し、同等機能の重複実装をしない  
2. 変更は最小差分で行い、理由を説明する  
3. レスポンシブ対応を前提に実装する  
4. URL方針を遵守する  
   - `/price/` 形式
   - `index.html` 非表示
   - `www` なし（またはプロジェクトで定義した正規ホスト）
   - `http` から `https` へ転送
