# COMPONENT_REGISTRY_TEMPLATE

## 記録ルール

- 新規コンポーネント追加時に必ず追記
- 既存コンポーネント変更時は用途・依存関係を更新
- 置換・廃止した場合は履歴を残す

## テンプレート

### `ComponentName`

- **パス**: `src/components/...`
- **責務**: 何を担当するか
- **使用箇所**: どこで使うか
- **主要Props**:
  - `propA: type` - 説明
  - `propB?: type` - 説明
- **レスポンシブ要件**: モバイル/タブレット/PC での挙動
- **備考**: 禁止事項や注意点
