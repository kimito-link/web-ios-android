りんく

Capacitor iOS ビルド・スクショ30枚・説明文・Review Notes・審査提出・配信地域175か国まで、ios-appstore-release.yml が自動でやるよ。

  • iOS ビルド（GitHub Actions・macOS ランナー・Mac 不要）
  • ブランド別アイコン生成（RH は generate-app-icon-reverse-hack.mjs）
  • アイコン・スクショ（iPhone / iPad）の生成と ASC アップロード
  • 説明文・年齢レーティング・価格（無料）の API 同期
  • 審査提出（WAITING_FOR_REVIEW まで）
  • 配信地域（全世界 175/175・日本含む）— appstore-submit.mjs の [7g]
▶ 配信地域だけ軽く直したいとき（タップで開く）

フルビルドなしで全世界配信だけ設定する軽量ジョブ:

  • GitHub Actions → asc-set-availability → brand を選んで Run
  • ローカル: npm run asc:set-availability:reverse-hack（ASC API キー要）

成功ログ: worldwide availability OK (175/175 territories, JPN=yes)
