1
署名まわり（初回だけ） 人間（30〜40分）
Apple Developer + App Store Connect API キー
  • pwsh scripts/create-ios-csr.ps1 → CSR と秘密鍵
  • Apple Developer で Apple Distribution 証明書（⚠️ .csr.pem をアップロード。DER は Invalid CSR）
  • App Store Connect 用 Provisioning Profile を発行 → ios-signing/ に保存
  • App Store Connect → ユーザーとアクセス → キー → API キー（.p8）を発行
  • pwsh scripts/prepare-openci-ios-secrets.ps1 → GitHub Secrets 7個を登録
Secrets（7個） IOS_DIST_CERT_P12_BASE64 / IOS_DIST_CERT_PASSWORD / IOS_APPSTORE_PROFILE_BASE64 / APPLE_TEAM_ID / APPSTORE_CONNECT_KEY_ID / APPSTORE_CONNECT_ISSUER_ID / APPSTORE_CONNECT_API_KEY_P8_BASE64
2
App Store Connect で「アプリの枠」を作る 人間（5分）
API では新規アプリ作成不可。ここだけ手作業
  • appstoreconnect.apple.com/apps → ＋ → 新規 App
  • 名前 = displayName、言語 = 日本語、Bundle ID = identity.bundleId（事前に Developer で explicit 登録）
  • SKU は任意（例: webhealthcheck2026）
  • 作成後、URL の数字 or アプリ情報 → Apple ID を stores.ascAppId に記入
3
App のプライバシー（データ使用状況） 人間（2分・1回だけ）
API が 404 のため完全自動化不可。アプリ単位で永続
⚠️ 審査ブロッカー実例: STATE_ERROR.APP_DATA_USAGES_REQUIRED — Privacy 未公開だと submit が 409 で止まる。
  • App Store Connect → 自分のアプリ → App のプライバシー（配信 → プライバシー）
  • 「いいえ、このAppではデータを収集しません」→ 公開
  • プライバシーポリシー URL = contact.privacyUrl（例: https://web-health-check.link/privacy-policy.html）
✅ 1回設定すれば以降の CI submit は全部通る。API の /v1/appDataUsages は PATH_ERROR 404（2026-06 時点）。
4
main に push → CI が審査提出 AI（自動）
workflow: ios-appstore-release.yml
  • アイコン変更: release-assets/appstore/app-icon-1024.png をコミット → CI が @capacitor/assets で全サイズ生成
  • 審査中にアイコン差し替え: 旧提出を canceled: true で取下げ → 新 build を link → 再 submit
  • 成功ログ: final state=WAITING_FOR_REVIEW / DONE.
🍎 審査通過後だけ: App Store Connect → 価格と配信可能状況 → 配信地域 をオン（未設定だと DL できない・最大24h）
5
人間チェックリスト（初回）
  • Bundle ID を Developer Identifiers に explicit 登録した
  • ASC でアプリ枠を作り ascAppId を app.config.json に書いた
  • GitHub Secrets 7個を入れた
  • App Privacy を「収集しない」で公開した
  • push 後、ASC で「審査待ち」と新アイコンを目視確認した
