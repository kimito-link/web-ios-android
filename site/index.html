② 名前と連絡先を書くだけ

アプリの名前・メールを入力する

フォルダの中に app.config.json というファイルがあります。メモ帳で開いて、アプリ名・サイトのURL・メールアドレスの3箇所を書き換えるだけ。あとは全部そのままでOKです。

③ AIにお願いする

Claude（AI）にセットアップしてもらう

Claude や ChatGPT などのAIに、「このフォルダのパスを渡して npm run setup を実行して」と伝えるだけ。アイコン作成・プライバシーページ・各種設定など、面倒なことを全部やってくれます。

🤖 エラーが出ても大丈夫。画面をスクショしてAIに貼るだけで解決してくれます。
npm run setup

「送信」したら完成！

GitHubにアップロード（「プッシュ」）するだけで、iPhone用・Android用のアプリが裏で自動でつくられ、App Store と Google Play に自動で申請されます。

⏳ ストアの審査に数日かかります。通ればそのまま公開されます。
git push origin main

💡 なぜ作ったのか

たぬ姉

クリエイターがアイデアに集中できるように

アプリを作るとき、本当に大変なのはビルド設定・証明書の管理・ストアへの提出手続きです。 いいアイデアがあっても、技術的なハードルで諦めてしまう人をたくさん見てきました。

このテンプレートは、Kimito Link のクリエイター支援活動の一環として作りました。 面倒な部分をぜんぶ自動化して、アイデアやコンテンツに集中できる環境を届けたいのです。

包丁はプロの料理人が使えばプロの味になる。その辺の人が使えばその辺の料理になる。 AIも同じです。道具の性能ではなく、使う人間の積み重ねが結果を決めます。

Kimito Link がやっているのは「作業代行」ではありません。 アイデアを持つ人と、技術・判断力を持つ人間が対等に組んで、よいものを一緒に作る。 そういう関係を大切にしています。

無料でオープンソースで公開しています。必要な方に届けば、それで十分です。
