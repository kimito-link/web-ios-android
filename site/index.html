Web + iOS + Android 自動化テンプレート

アプリ名を決めたら
あとはClaudeにおまかせ！

Web・iOS・Android を同時にリリースできる
自動化テンプレートです。むずかしいことは全部やってくれます。

GitHubで使ってみる →

📋 はじめる前の準備（開発者登録ガイド）を読む →

📋 使い方は たった4ステップ

りんく
ステップ 1

テンプレートをコピーする

GitHubの「Use this template」ボタンをポチッと押すだけ。自分のリポジトリが自動で作られます。フォルダ名がそのままアプリ名になります。

こん太
ステップ 2

アプリの名前と情報を書く

app.config.json というファイルを開いて、アプリ名・ドメイン・メールアドレスだけ書き換えます。ここだけがアプリごとに違う部分です。あとは全部自動！

たぬ姉
ステップ 3

セットアップを実行する

ターミナルで1行打つだけ。アイコン生成・プライバシーページ作成・Android設定など、全部自動でやってくれます。必要なGitHub Secretsの一覧も出してくれます。

npm run setup
りんく
ステップ 4

プッシュしたら完成！

GitHubにアップロードするだけで、App Store と Google Play への提出が自動で始まります。あとは審査を待つだけです。

git push origin main

🤖 自動でできること・できないこと

むずかしい作業はぜんぶ自動！
初回だけ15分だけ手動があるよ。
作業自動？説明
Webアプリのデプロイ（Vercel） ✅ 自動 git push するだけ
iOSアプリのビルド・App Store提出 ✅ 自動 GitHub Actionsが動く
Androidアプリのビルド・Google Play提出 ✅ 自動 GitHub Actionsが動く
アイコン・スクリーンショット生成 ✅ 自動 元画像1枚から全サイズ自動生成
ストア掲載情報（テキスト・画像） ✅ 自動 app.config.jsonから自動設定
プライバシーポリシーページ ✅ 自動 設定情報から自動生成
広告・ターゲットユーザーの申告 ✋ 初回のみ Play ConsoleでGUI操作（約15分）
コンテンツレーティング（IARC） ✋ 初回のみ アンケートに答えるだけ
Apple / Google の審査 ⏳ 待つだけ iOS: 1〜3日、Android: 数日
