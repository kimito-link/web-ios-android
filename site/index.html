りんく
① まずここから

ひな形をコピーする

GitHub（無料で使えるソースコード置き場）を開いて、「Use this template」というボタンをクリックするだけ。アプリの土台がそっくりそのまま自分のものになります。

📌 GitHubのアカウントがない方は先に無料登録を。メールアドレスだけでOKです。

こん太
② 次にここ

アプリの名前・連絡先を書く

コピーしたフォルダの中に app.config.json というファイルがあります。メモ帳で開いて、アプリの名前・ウェブアドレス・メールアドレスを書き換えるだけ。

✏️ 変えるのは3箇所だけ。あとは全部そのままでOKです。

たぬ姉
③ AIに頼む

Claude（AI）にセットアップしてもらう

Claude（またはCursorなどのAI）に「このフォルダのパスを渡して、npm run setup を実行して」と頼むだけ。アイコン作成・プライバシーページ・各種設定など、ぜんぶ自動でやってくれます。

🤖 わからないことはAIに聞けば教えてくれます。エラーが出ても画面をスクショして貼れば解決してくれます。

npm run setup
りんく
④ あとは待つだけ

送信ボタンを押したら完成！

GitHubに「アップロード（プッシュ）」するだけで、iPhone用・Android用のアプリが自動でビルドされ、App Store と Google Play に自動で提出されます。

⏳ 審査には数日かかります。通ればそのままストアに並びます。

git push origin main

🤖 自動でできること・できないこと

むずかしい作業はぜんぶ自動！
初回だけ15分だけ手動があるよ。
作業自動？説明
Webアプリのデプロイ（Vercel） ✅ 自動 git push するだけ
iOSアプリのビルド・App Store提出 ✅ 自動 GitHub Actionsが動く
Androidアプリのビルド・Google Play提出 ✅ 自動 GitHub Actionsが動く
アイコン・スクリーンショット生成 ✅ 自動 元画像1枚から全サイズ自動生成
ストア掲載情報（テキスト・画像） ✅ 自動 app.config.jsonから自動設定
プライバシーポリシーページ ✅ 自動 設定情報から自動生成
広告・ターゲットユーザーの申告 ✋ 初回のみ Play ConsoleでGUI操作（約15分）
コンテンツレーティング（IARC） ✋ 初回のみ アンケートに答えるだけ
Apple / Google の審査 ⏳ 待つだけ iOS: 1〜3日、Android: 数日

画面をスクショして貼る

「この画面、こう直して」とスクショを貼るだけ。AIがデザインやレイアウトの問題をすぐに把握して修正案を出してくれます。

📂

フォルダのパスを伝える

ローカルのプロジェクトフォルダのパスをそのままAIに渡すと、コードを直接読んで修正してくれます。

"C:\Users\yourname\github\my-app"

たぬ姉

クリエイターがアイデアに集中できるように

アプリを作るとき、本当に大変なのはビルド設定や証明書の管理、ストアへの提出手続きです。 せっかくいいアイデアがあっても、技術的なハードルで諦めてしまうクリエイターをたくさん見てきました。

このテンプレートは、Kimito Link のクリエイター支援活動の一環として作りました。 「アプリを出したい」と思ったとき、面倒な部分はぜんぶ自動化して、 クリエイターがコンテンツやデザインに集中できる環境を届けたいのです。

ひとつ、正直にお伝えします。
「AIがあれば誰でもできるんでしょ」と思うなら、ぜひご自身でやってみてください。 それが一番早いです。

包丁はプロの料理人が使えばプロの味になる。その辺の人が使えばその辺の料理になる。 AIも同じです。道具の性能ではなく、それを使う人間の積み重ねが結果を決めます。 クリエイターはAIを使いこなすために、何年もの時間・お金・プライベートのすべてを注ぎ込んで 技術と判断力を身につけています。

Kimito Link がやっているのは「作業代行」ではありません。 アイデアや想いを持つ人と、技術と判断力を持つ人間が対等に組んで、 はじめてよいものが生まれると思っています。 お互いの仕事を尊重し、敬意を持って一緒に作れる方と歩んでいきたいと思っています。

無料でオープンソースで公開しています。必要な方に届けば、それで十分です。
