Web + iOS + Android を同時にリリースできる自動化テンプレート。
難しいことはぜんぶスクリプトがやってくれます。

GitHubで使ってみる →

📋 使い方（4ステップ）

  1. 1

    テンプレートをコピーする

    GitHubの「Use this template」ボタンを押して、自分のリポジトリを作ります。

  2. 2

    アプリの名前と情報を入力する

    app.config.json というファイルを開いて、アプリ名・ドメイン・メールアドレスだけ書き換えます。ここだけがアプリごとに違う部分です。

  3. 3

    セットアップを実行する

    ターミナルで1行打つだけ。アイコン生成・プライバシーページ作成・Android設定など、ぜんぶ自動でやってくれます。

    npm run setup
  4. 4

    プッシュしたら完成

    GitHubにアップロードするだけで、App Store と Google Play への提出が自動で始まります。

    git push origin main

🤖 自動でできること・できないこと

作業 自動？ 説明
Webアプリのデプロイ（Vercel） ✅ 自動 git push するだけ
iOSアプリのビルド・App Store提出 ✅ 自動 GitHub Actionsが動く
Androidアプリのビルド・Google Play提出 ✅ 自動 GitHub Actionsが動く
アイコン・スクリーンショット生成 ✅ 自動 元画像1枚から全サイズ生成
ストア掲載情報（テキスト・画像） ✅ 自動 app.config.jsonから自動設定
プライバシーポリシーページ ✅ 自動 config情報から自動生成
広告・ターゲットユーザーの申告 ✋ 初回のみ Play ConsoleでGUI操作（約15分）
コンテンツレーティング（IARC） ✋ 初回のみ アンケートに答えるだけ
Apple/Google の審査 ⏳ 待つだけ iOS: 1〜3日、Android: 数日

⚙️ 変えるのはここだけ

このファイルを書き換えるだけで、すべてのスクリプトが新しいアプリ用に動きます。

{
  "identity": {
    "displayName": "マイアプリ", ← アプリ名
    "bundleId": "com.example.myapp", ← Bundle ID
    "productionDomain": "myapp.example.com" ← ドメイン
  },
  "contact": {
    "email": "you@example.com" ← 連絡先メール
  }
  // あとは自動で埋まる
}
