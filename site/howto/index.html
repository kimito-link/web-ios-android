アプリを公開するまでに必要な4つの準備を、それぞれ画面つきで説明する専用ページにまとめました。 上から順に①→②→③→④と進めれば、迷わず独自ドメインでの公開まで辿り着けます。

  • STEP1 GitHub — コードを保存する「無料の倉庫」にテンプレートを置く
  • STEP2 Vercel — GitHubと連携してWebサイトを自動で公開する
  • STEP3 ドメイン取得 — 「自分だけのURL」を購入する
  • STEP4 Cloudflare — ドメインとVercelをつなぎ、独自ドメインで公開する
