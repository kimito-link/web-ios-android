🐙 GitHub（ギットハブ）とは？

コードを保存する「無料の倉庫」です
GitHubはね、プログラムのファイルをインターネット上に保存しておける場所だよ。
無料で使えて、ここにファイルを置くだけでアプリが自動で公開されるんだ！
